# smart-distance-monitor
Using an ultrasound (HC-SR04) with a servo (SG90) that monitors distance. (No glue gun so I had to use a rubber band).
The HC-SR04 ultrasonic sensor measures the distance to nearby objects. The Arduino reads the distance and controls the SG90 servo motor according to the programmed behaviour. The servo sweeps between 0° and 180° while the sensor readings are displayed in the Serial Monitor.
