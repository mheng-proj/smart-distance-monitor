# smart-distance-monitor
It is able to scan the distance from the sensor to an obstacle it faces from 0 degrees to 180 degrees. I made this as a stepping stone for my Obstacle Avoiding Robot.

# Components Used

- Any Arduino/ Arduino-like Model
- Ultrasound Sensor HC-SR04
- Servo SG90
- 2 RubberBands
- Jumper Wires

# How It Works

Rotates 0 to 180 degrees constantly and outputs a message depending on how close the obstacle is in front of the sensor. Servo rotates as the Ultrasound Sensor calculates the distance.

# Challenges Encountered

Problem 1: Attaching Ultrasound Sensor over Servo

Issue: Materials available

Cause: The materials I thought of attaching it together was glue gun but it would melt/damage the component and tape was too weak.

Solution: Used rubber bands to attach it over and balanced it well to prevent any slips.
